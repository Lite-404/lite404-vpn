Lite404 VPN для компьютера
==========================

Программа открывает окно в браузере (адрес http://127.0.0.1:47404).
Войдите токеном из бота @lite404bot (раздел «Приложение») — тем же, что и на телефоне.
Компьютер занимает одно место в лимите устройств подписки.

Как работает: внутри Xray, при подключении включается системный прокси
(браузеры, Telegram Desktop и большинство программ идут через VPN).
Для программ, которые не видят системный прокси: HTTP 127.0.0.1:10809, SOCKS5 127.0.0.1:10808.
Локальная сеть (192.168.x.x, роутер, принтер) по умолчанию работает напрямую.
Умная маршрутизация: российские сайты напрямую, реклама и торренты блокируются,
остальное через VPN. Можно выключить: «Всё через VPN». Локальную сеть можно пустить через VPN
(переключатель «Локальная сеть напрямую»).

Закрыть программу — кнопка «Закрыть программу» внизу окна (VPN отключится, прокси снимется).
Если окно браузера закрыли — запустите программу ещё раз, окно откроется снова.

Windows: распакуйте папку куда угодно и запустите «Lite404 VPN.exe».
  Если SmartScreen предупредит — «Подробнее» → «Выполнить в любом случае».

macOS: перетащите «Lite404 VPN.app» в «Программы». Первый запуск — правый клик → «Открыть» → «Открыть»
  (программа не подписана сертификатом Apple). Если macOS пишет «повреждено»:
  в Терминале выполните  xattr -cr "/Applications/Lite404 VPN.app"
  Apple Silicon (M1–M4) — архив apple-silicon, старые Mac на Intel — intel.

Linux: tar xzf Lite404-VPN-*.tar.gz && ./lite404-vpn/lite404-vpn
  Системный прокси включается в GNOME и похожих (через gsettings), в остальных укажите прокси вручную.

Резервного VPN (туннель ВКонтакте) в версии для компьютера пока нет — он есть в Android-приложении.

Настройки и журнал: Windows %APPDATA%\Lite404, macOS ~/Library/Application Support/Lite404, Linux ~/.config/Lite404.
